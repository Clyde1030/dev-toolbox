# dev-toolbox

Personal toolbox: knowledge base, Python tools (uv workspace), Excel templates.

| Path | Contents |
| --- | --- |
| `tools/` | uv workspace members (`pdf-merger`, `sqlserver-utils`) and standalone projects (`bank-query`, `exposures`) |
| `tools/scripts/` | One-off Python scripts (`Formatter`, `LettersMacro`, `Tableau`, `processing/` carrier modules, `notebooks/`, ...) |
| `tools/launchers/` | Windows `.bat` launchers (`EasyRunner`, drag-and-drop validator) |
| `sql/` | Standalone SQL (error handler, metadata queries) |
| `excel-templates/` | `.xlsm` templates and their exported VBA / Magnastar SQL (`vba/`) |
| `knowledge-base/` | Notes: `aws/` (Udemy course), `claude/` (Claude Code usage guide), `new-environment-setup/` (MacBook setup, Linux, VS Code settings), `sql-server/RSDB/`, `terraform/`, `processes/`, ... |
| `_archive/` | Ignored by git; parking spot for retired files |
